Sobre o IFG-Eventos

Plataforma web desenvolvida como projeto final de interação com APIs para o curso de Bacharelado em Sistemas de Informação do Instituto Federal de Goiás (IFG) – Câmpus Goiânia.

Objetivo do Sistema

O IFG-Eventos foi projetado para centralizar e facilitar a divulgação de palestras, oficinas, feiras científicas e atividades culturais realizadas no ambiente acadêmico.

Do ponto de vista técnico, a aplicação demonstra a integração entre uma interface web desenvolvida em Django e o consumo/manipulação de dados via API, aplicando conceitos de autenticação de usuários, controle de permissões e requisições dinâmicas.

Python Django Framework Integração com API HTML5 & CSS3

Como utilizar a plataforma

Siga o passo a passo abaixo para explorar todos os recursos disponíveis no sistema:

1

Crie sua Conta

Acesse a aba Criar conta no menu superior para registrar seu usuário e senha no sistema.

2

Explore os Eventos

Clique em Lista Eventos para visualizar a programação completa com datas, locais e detalhes.

3

Gerenciamento (Admin)

Usuários administradores têm acesso exclusivo ao cadastro de novos eventos e às configurações do sistema.
